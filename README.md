# Roznitsa Procurement Control

Контроль подбора товаров для проекта «Розница»: правила, автоматические проверки и тесты, которые не дают повторять уже выявленные ошибки.

## Назначение репозитория

- `REGLEMENT.md` — рабочая Markdown-версия актуального регламента.
- `rules/procurement_rules.json` — машинно-читаемые жёсткие правила и исключения.
- `scripts/validator.py` — валидация выбранной позиции и итоговой строки.
- `scripts/matcher.py` — базовая оценка допустимости аналога до сравнения цены.
- `tests/` — регрессионные тесты на реальные ошибки проекта.
- `.github/workflows/tests.yml` — автоматический запуск тестов на GitHub.

## Главный принцип

Сначала проверяется смысловая допустимость товара, затем источник/поставщик/производитель/остаток/вложимость, и только после этого цена в сопоставимой единице.

Последняя явная инструкция пользователя имеет приоритет над более ранними формулировками регламента.

## Локальный запуск

```bash
python -m pip install pytest
pytest -q
```

Код намеренно использует только стандартную библиотеку Python; `pytest` нужен только для тестов.
