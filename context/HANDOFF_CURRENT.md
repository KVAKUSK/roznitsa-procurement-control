Источники/подсказки внутри/рядом с проектом:

- актуальные прайсы поставщиков — источник текущей цены, наличия и поставщика;
- исторический лист НЕ является источником текущей цены.

## 2. Кто такая «Лена» в таблице

Пользователь = Лена. Колонка `Лена комментарий` пишется от её лица и должна быть короткой.

Нормальный формат комментария:
`30 шт/кор; ООО «Ресурс»; 25,82 ₽/шт`

Не писать в комментарии:
- слово «вложимость»;
- название источника/прайса и номер строки;
- длинные объяснения;
- `производитель не подтвержден`;
- `подбор снят`.

Если цена уже стоит в отдельной колонке и расчёт на штуку не нужен — комментарий можно оставить как `NN шт/кор; Производитель`.

## 3. Главный принцип подбора

Пустых рабочих строк быть не должно. Для каждой рабочей позиции должно быть либо:
- `ДА`, если найден фактически тот же товар (допустимы сокращения/другой порядок слов), либо
- настоящий, осмысленный аналог.

Нельзя закрывать строку случайным товаром только ради отсутствия пустоты.

Порядок выбора аналога:
1. Сначала ЖЁСТКО товарная категория.
2. Затем формат/тип упаковки.
3. Затем масса/объём.
4. Затем бренд/линейка.
5. Затем вкус/вариант.
6. И только после этого — цена среди сопоставимых вариантов.

Примеры жёстких правил:
- бульон → бульон;
- суп → суп;
- крем-суп/суп-пюре → сначала крем-суп/суп-пюре, затем близкий суп;
- картофельное пюре → картофельное пюре;
- рисовое готовое блюдо → рис/готовое блюдо, не лапша;
- мягкая пачка → в первую очередь мягкая пачка;
- чашка/лоток → в первую очередь тот же формат.

## 4. Масса и ассортимент

Нельзя выбирать 40 г, если в прайсах есть нормальный близкий вариант 70–75 г для запроса 72 г.

Нельзя одним и тем же аналогом закрывать большой ассортимент. Раньше была ошибка: Ottogi Yukgaejang и Doshirak попадали в слишком большое число разных строк.

Обязательное правило разнообразия:
- искать ассортимент у нескольких подходящих производителей;
- особенно внимательно смотреть прайс Кима по корейской лапше;
- Nongshim, Ottogi, Samyang, DAESANG, Simeite и др. не смешивать без необходимости;
- один и тот же аналог повторять только когда он действительно лучший вариант.

## 5. Историческая вкладка `Прод июль-сент 25`

Использовать как обязательную подсказку:
- проверить, встречалась ли такая же или близкая позиция раньше;
- посмотреть прошлый товар, поставщика, фасовку и смысл соответствия;
- если новый алгоритм предлагает принципиально другой товар — это триггер на ручную перепроверку.

Но текущие цена/поставщик/наличие всегда подтверждаются по актуальному прайсу.

## 6. Поставщики и специальные правила

- `Тэн` — полностью исключён.
- `Че Ман Су` — полностью исключён.
- `Восток` разрешён для позиций из `Прайс Орими`; при этом поставщик = `Восток`, а `Орими` — производитель/группа, НЕ поставщик.
- Richard из Project Invest → поставщик `Проект Инвест`.
- Greenfield / Jardin / Jockey / TESS из `Прайс Орими` → поставщик `Восток`.
- Махеевъ — использовать из Амбирса.
- Владторг не исключается автоматически.

Поставщик в итоговой строке = тот, чей актуальный прайс содержит выбранную позицию.

## 7. Производитель

Производитель обязателен. Поставщик и производитель — разные сущности.

Если производителя нет в прайсе, разрешён поиск по открытым источникам. Нельзя оставлять финальный комментарий `производитель не подтвержден`.

Частые подтверждённые соответствия:
- Nongshim → Nongshim Co., Ltd.
- Ottogi → Ottogi Corporation.
- Samyang → Samyang Foods Co., Ltd.
- Doshirak / Квисти → ООО «Доширак Коя».
- Big Lunch / Бизнес Ланч → ООО ТПК «БиоФуд».
- Увелка → ООО «Ресурс».
- Greenfield / TESS / Jardin / Жокей → ООО «Орими».

## 9. Что проверено в текущем `РР1_перепроверено_финал.xlsx`

Последняя техническая проверка сохранённого файла:
- рабочих строк: 1123;
- пустых выборов: 0;
- запрещённых/неверно названных поставщиков (`Тэн`, `Че Ман Су`, `Орими` как поставщик): 0;
- пустых комментариев Лены: 0;
- старых служебных фраз типа `подбор снят`, `не подтвержден`, `источник`: 0.

Важно: это не означает, что каждая позиция идеальна семантически. При следующих правках всё равно применять бизнес-логику выше, а не доверять автоматическому совпадению вслепую.

## 10. Инструментальная логика

Для Excel-правок использовать установленный spreadsheet workflow / artifact_tool, не openpyxl.

После основного подбора нужен отдельный аудит:
- переходы между категориями;
- слишком большая разница массы;
- повтор одного аналога в большом числе строк;
- несоответствие поставщика актуальному прайсу;
- пустой/неверный производитель;
- запрещённые поставщики;
- пустые рабочие позиции.

Data Analytics использовать именно как независимый аудит качества, а не как источник цены.
